# Changelog

## 1.902 — 2026-11-07

First tagged release of the standalone Dyekon OFL distribution.

- Includes Dyekon, Dyekon Text, and Dyekon Mono: 21 faces in TTF and WOFF2.
- Packages the approved Round21b font files unchanged. Every supplied TTF reports `Version 1.902`.
- Includes web CSS, installation instructions, the SIL Open Font License 1.1, and SHA-256 checksums.
- Adds explicit package version metadata and a downloadable release archive.

This date records publication of the standalone release, not a new font build.
